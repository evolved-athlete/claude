# Nutrient Food Sources

> **Type:** Reference  
> **Topics:** vitamins, minerals, food sources, high-nutrient day  
> Source: Kate Deering, *How to Heal Your Metabolism* (2015). These are the author's positions (influenced by Ray Peat), not mainstream consensus. Present them as "the book recommends...".

| Nutrient | Best food sources (per book) |
|---|---|
| Vitamin A | beef liver, eggs, cheese, milk |
| B1 | potato, liver, eggs, pork, coffee |
| B2 | liver, cheese, eggs, kidney |
| B3 | beef, fish, coffee |
| B5 | eggs, meat, yogurt |
| B6 | liver, eggs, meat, chicken, bananas, carrots (animal B6 is ~100% bioavailable) |
| Biotin | egg yolk, liver |
| Folate / B12 | liver, eggs, dairy, meat, seafood |
| Vitamin C | OJ, peppers, papaya, pineapple, kiwi, watermelon, potatoes |
| Vitamin D | sun, dairy, liquid D3 (Carlson's) |
| Vitamin E | egg yolk, liver |
| Vitamin K | ghee, butter oil, egg yolk, Gouda, foie gras, natto, mineral broth |
| Calcium | dairy, bone broth, eggshell calcium |
| Magnesium | coffee, dark chocolate, fruit, bone or mineral broth, **Epsom salt baths** |
| Potassium | OJ, fruit, potatoes, bamboo shoots, coconut water |
| Sodium | white salt |
| Zinc | oysters, beef, lamb, shrimp |
| Copper | oysters and shellfish, liver, potatoes |
| Selenium | shellfish, liver, beef, lamb |
| Iron | liver, beef, mussels, oysters, fish |

**Weekly "high-nutrient day":** at least once a week, include **liver** (vitamins A and B, selenium) and **oysters or other shellfish** (zinc, copper, selenium), plus extra milk and OJ.
