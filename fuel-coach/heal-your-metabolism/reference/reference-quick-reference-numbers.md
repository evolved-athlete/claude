# Quick-Reference Numbers

> **Type:** Reference  
> **Topics:** numbers, doses, frequencies, targets  
> Source: Kate Deering, *How to Heal Your Metabolism* (2015). These are the author's positions (influenced by Ray Peat), not mainstream consensus. Present them as "the book recommends...".

| Item | Value |
|---|---|
| Healthy waking temperature (armpit, 10 min) | ≥ 97.8 °F / 36.6 °C |
| Midday temperature | ~98.6 °F / 37 °C (FAQ: 98–99 °F) |
| Resting pulse | 75–90 bpm |
| Sleep | 7–9 uninterrupted hours |
| Bowel movements | 1–3/day |
| Urination | ~4–6×/day |
| Metabolic-rate drop per 1 °C | 10–13% |
| Macros | Carbs 40–70% (start ~50) · Protein 20–30% (start ~25) · Fat 20–30% |
| Meal size / snack size | 300–700 kcal / 100–300 kcal |
| Meals per day | ≥ 6; 8–10 if metabolically compromised |
| Meal duration | 20–30 minutes, 10–15 chews per bite |
| Coconut oil | 1 tsp/day, +1 tsp/week → 1–2 Tbsp/day |
| Milk / dairy | 2–6 servings/day |
| Eggs | up to 2/day (pastured) |
| Liver | 3–6 oz every 7–10 days |
| Shellfish | 1–3×/week |
| White fish | 2–4×/week; fatty fish 1–2×/month |
| Muscle meat | 2–3×/week if healthy; avoid if inflamed or hypometabolic; always with 1 cup broth or 1 Tbsp gelatin |
| Bone broth | 1–2 cups/day healthy; 3–4+ hypometabolic |
| Gelatin | 1–6 Tbsp/day |
| Broth + gelatin share of protein | 25–35% healthy; up to 50% compromised |
| Raw carrot | 1–2/day |
| Eggshell calcium | ¼ tsp, 1–3×/day with food (low-dairy diets) |
| Mineral broth | 1–2 shots/day |
| Coffee | with calories; 3–5 cups in the research cited |
| Sodium (research cited) | lowest risk at 3,000–6,000 mg/day; salt to taste |
| Nuts | 1–2×/week max if healthy (soaked/sprouted, low-PUFA); 1–2×/month while healing |
| Legumes | 1–2×/month at most while healing |
| Exercise while healing | 30–45 min, HR < 100, light/moderate |
| Intense exercise when healthy | ≤ 2–3×/week |
| Pre-workout | 200–400 kcal, 30–60 min before |
| Post-workout window | up to 2 h; milk + sugar + gelatin |
| Lactose reintroduction | 1–2 oz/day milk, +1 oz/day each week |
| Grain elimination test | 30 days minimum |
| Eating out | 1–2×/week; ask for butter or olive oil |
